# Swiggy SQL Data Analysis Project

## Project Overview
This project focuses on analysing Swiggy restaurant data using MySQL. The objective is to extract meaningful business insights about restaurants, cities, cuisines, ratings and pricing.

## Tools Used
- MySQL
- MySQL Workbench
- SQL
- GitHub

## Dataset
The dataset contains information about:
- Restaurant names
- Cities
- Ratings
- Rating counts
- Cost for two
- Cuisines
- Restaurant addresses

## Business Questions Solved

1. How many restaurants are listed per city?
2. What are the most popular cuisines across India?
3. Which restaurant chains have the most branches?
4. Which cities have the highest average restaurant ratings?
5. What is the average cost for two across cities?
6. Which cuisines have the highest average ratings?
7. Which restaurants have ratings above 4.5 and more than 1,000 ratings?
8. Which cities offer the best value for money?
